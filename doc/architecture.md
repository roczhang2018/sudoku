## 🎯 项目概述

本项目是一个零依赖的原生Web贪吃蛇对战游戏，采用模块化设计，支持用户认证、游戏记录、音效系统等功能。

### 核心特性
- 玩家 vs AI 对战模式
- 3条生命系统
- 3-5个食物同时存在
- 背景音乐和音效
- 无限循环模式切换
- 用户注册登录系统
- 详细游戏记录功能

## 🔧 模块设计

### 1. 入口层 (main.js)

**职责**: 应用程序入口点，负责初始化各个模块

**主要功能**:
- DOM加载完成后初始化
- 创建AuthManager和SnakeGame实例
- 绑定全局事件处理器

**关键代码**:
```javascript
document.addEventListener('DOMContentLoaded', () => {
  const authManager = new AuthManager();
  const currentUser = authManager.getCurrentUser();
  const game = new SnakeGame(authManager, currentUser);
  game.init();
});
```

### 2. 认证层 (auth.js)

**职责**: 用户认证和会话管理

**主要功能**:
- 用户注册/登录
- 密码验证和哈希
- 会话管理
- 用户数据存储
- 游客模式支持

**核心类**: `AuthManager`

**关键方法**:
- `registerUser()` - 用户注册
- `loginUser()` - 用户登录
- `logout()` - 用户登出
- `getCurrentUser()` - 获取当前用户
- `updateUser()` - 更新用户数据

### 3. 游戏核心层 (game.js)

**职责**: 主游戏逻辑控制和协调

**主要功能**:
- 游戏状态管理
- 游戏循环控制
- 碰撞检测
- 分数计算
- 生命管理
- 游戏记录

**核心类**: `SnakeGame`

**关键方法**:
- `init()` - 游戏初始化
- `startGame()` - 开始游戏
- `gameLoop()` - 游戏主循环
- `checkCollisions()` - 碰撞检测
- `gameOver()` - 游戏结束处理

### 4. 状态管理层 (gameState.js)

**职责**: 游戏状态和数据的集中管理

**主要功能**:
- 游戏状态维护
- 分数管理
- 生命值管理
- 游戏记录管理
- 本地存储操作

**核心类**: `GameState`

**关键属性**:
- `gameState` - 当前游戏状态
- `score` - 玩家分数
- `aiScore` - AI分数
- `highScore` - 最高分
- `lives` - 生命数
- `gameRecords` - 游戏记录数组

### 5. 音频层 (audio.js)

**职责**: 音频系统管理

**主要功能**:
- Web Audio API初始化
- 背景音乐播放
- 游戏音效生成
- 音频开关控制

**核心类**: `AudioManager`

**关键方法**:
- `init()` - 音频系统初始化
- `startBackgroundMusic()` - 开始背景音乐
- `playSound()` - 播放音效
- `toggleMusic()` - 切换音乐开关

### 6. 蛇逻辑层 (snake.js)

**职责**: 蛇的移动和AI逻辑

**主要功能**:
- 玩家蛇移动控制
- AI蛇智能移动
- 碰撞检测
- 颜色变化

**核心类**: `Snake`, `AISnake`

**关键方法**:
- `move()` - 蛇移动
- `setDirection()` - 设置方向
- `checkCollision()` - 碰撞检测
- `changeColor()` - 颜色变化

### 7. 食物管理层 (food.js)

**职责**: 食物生成和管理

**主要功能**:
- 食物生成(3-5个)
- 位置验证
- 颜色管理
- 食物移除

**核心类**: `FoodManager`

**关键方法**:
- `generateFood()` - 生成食物
- `removeFood()` - 移除食物
- `getFoods()` - 获取食物列表

### 8. 渲染层 (renderer.js)

**职责**: 游戏画面渲染

**主要功能**:
- Canvas绘制
- 网格渲染
- 蛇身渲染
- 食物渲染
- 边界箭头渲染

**核心类**: `Renderer`

**关键方法**:
- `render()` - 主渲染方法
- `clearCanvas()` - 清空画布
- `drawGrid()` - 绘制网格
- `drawSnake()` - 绘制蛇
- `drawFood()` - 绘制食物

### 9. UI控制层 (ui.js)

**职责**: 用户界面控制和事件处理

**主要功能**:
- DOM元素管理
- 事件绑定
- 按钮状态更新
- 分数显示
- 游戏记录模态框

**核心类**: `UIManager`

**关键方法**:
- `bindEvents()` - 绑定事件
- `updateScore()` - 更新分数显示
- `updateStatusText()` - 更新状态文本
- `showGameRecords()` - 显示游戏记录

### 10. 配置层 (config.js)

**职责**: 游戏配置和常量定义

**主要功能**:
- 网格尺寸配置
- 游戏状态枚举
- 方向定义
- 难度配置
- 颜色数组

**关键常量**:
- `GRID_SIZE` - 网格大小
- `CANVAS_WIDTH/HEIGHT` - 画布尺寸
- `GAME_STATES` - 游戏状态枚举
- `DIRECTIONS` - 方向定义
- `DIFFICULTY_CONFIG` - 难度配置

## 📊 数据流设计

### 用户输入流程

```
用户输入 → UI层 → 游戏逻辑层 → 状态管理层 → 渲染层 → 显示输出
    ↓         ↓         ↓           ↓         ↓
键盘事件 → 事件处理 → 游戏更新 → 状态更新 → 画面渲染
    ↓         ↓         ↓           ↓         ↓
鼠标点击 → 按钮响应 → 游戏控制 → 数据存储 → 视觉反馈
```

### 游戏循环流程

```
开始游戏 → 初始化 → 游戏循环 → 更新状态 → 渲染画面 → 检查结束条件
    ↓         ↓         ↓         ↓         ↓           ↓
设置状态 → 生成食物 → 移动蛇 → 碰撞检测 → 绘制画面 → 游戏结束？
    ↓         ↓         ↓         ↓         ↓           ↓
记录时间 → 分配位置 → 更新位置 → 处理碰撞 → 更新UI → 保存记录
```

## 🛠️ 技术栈

### 前端技术
- **HTML5**: 页面结构和Canvas元素
- **CSS3**: 样式设计和响应式布局
- **JavaScript ES6+**: 核心编程语言
- **Canvas API**: 游戏画面渲染
- **Web Audio API**: 音频系统

### 设计模式
- **模块化设计**: ES6模块系统
- **面向对象**: 类和继承
- **观察者模式**: 事件驱动
- **单例模式**: 全局状态管理

### 开发工具
- **Git**: 版本控制
- **本地服务器**: Python HTTP服务器

## 🎯 设计原则

### 1. 单一职责原则
每个模块只负责一个特定的功能，如：
- `audio.js` 只负责音频相关功能
- `renderer.js` 只负责画面渲染
- `food.js` 只负责食物管理

### 2. 模块化设计
- 使用ES6模块系统
- 清晰的模块边界
- 低耦合高内聚

### 3. 关注点分离
- 业务逻辑与UI分离
- 数据存储与业务逻辑分离
- 渲染与游戏逻辑分离

### 4. 可扩展性
- 易于添加新功能
- 支持不同游戏模式
- 模块化架构便于维护

### 5. 用户体验
- 响应式设计
- 流畅的动画效果
- 直观的用户界面
- 完整的错误处理

## 📈 性能优化

### 1. 渲染优化
- 使用Canvas进行高效渲染
