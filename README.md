# 贪吃蛇 Snake Game

本项目是一个零依赖的原生 Web 贪吃蛇对战游戏，包含：
- 玩家 vs AI 对战模式
- 3条生命系统
- 3-5个食物同时存在，全部吃完后重新分配
- 背景音乐和音效
- 无限循环模式切换
- 难度选择和速度控制
- **用户注册登录系统**
- **游客模式和用户模式**
- **详细游戏记录** - 记录每局游戏的时间、模式、时长、成绩和胜负结果

## 🎮 游戏特色

### 核心玩法
- **双蛇对战**：玩家蛇（绿色）vs AI蛇（红色）
- **生命系统**：每轮游戏3条生命，碰撞后重新开始
- **食物机制**：棋盘上同时存在3-5个不同颜色的食物
- **智能AI**：AI蛇会计算距离，优先吃最近的食物

### 游戏模式
- **无限循环模式**：蛇可以从边界穿越到对面
- **经典模式**：撞墙会失去生命
- **难度选择**：简单/中等/困难
- **速度控制**：实时调整游戏速度

### 音效系统
- **背景音乐**：自动播放"You and me we are family"
- **游戏音效**：吃食物、游戏开始/结束等音效
- **音量控制**：音乐和音效可独立开关

### 用户系统
- **游客模式**：无需注册即可游戏，成绩临时保存
- **用户注册**：支持用户名、密码、邮箱注册
- **登录验证**：安全的密码验证和会话管理
- **数据保存**：登录用户完整游戏数据保存
- **个人统计**：最高分、游戏次数、总分数记录

### 游戏记录系统
- **详细记录**：每局游戏自动记录开始时间、结束时间、游戏时长
- **模式记录**：记录游戏模式（无限循环/经典模式）和难度设置
- **成绩统计**：记录玩家分数、AI分数、胜负结果、使用生命数
- **历史查看**：通过"游戏记录"按钮查看所有历史记录
- **统计分析**：显示总游戏数、胜率、平均分、最高分等统计信息
- **数据管理**：支持清空记录，自动保存到本地存储

## 📁 项目结构

### 主要文件
- `index.html` - 游戏主页面和UI元素
- `login.html` - 用户登录/注册页面
- `style.css` - 游戏样式和响应式设计
- `auth.css` - 登录/注册页面样式
- `favicon.svg` - 网站图标

### 模块化代码结构（js/目录）
```
js/
├── config.js          # 游戏配置和常量
├── gameState.js       # 游戏状态管理
├── audio.js           # 音频系统管理
├── snake.js           # 蛇的移动和AI逻辑
├── food.js            # 食物生成和管理
├── renderer.js        # 渲染系统
├── ui.js              # UI控制和事件处理
├── auth.js            # 用户认证系统
├── game.js            # 主游戏逻辑
└── main.js            # 入口文件
```

### 各模块职责

#### 🎯 config.js - 游戏配置
- 网格尺寸、画布尺寸配置
- 游戏状态枚举、方向定义
- 难度配置、颜色数组

#### 🎮 gameState.js - 游戏状态管理
- 游戏状态（未开始/进行中/暂停/结束）
- 分数管理（玩家分数、AI分数、最高分）
- 生命值管理、蛇的位置和颜色
- 游戏记录管理（时间记录、记录创建、本地存储）

#### 🔊 audio.js - 音频系统
- Web Audio API 初始化
- 背景音乐播放（"You and me we are family"）
- 游戏音效（吃食物、游戏结束等）
- 音乐和音效开关控制

#### 🐍 snake.js - 蛇的逻辑
- **Snake类**：玩家蛇的基础功能（移动、转向、碰撞检测）
- **AISnake类**：AI蛇的智能移动逻辑
- 颜色处理工具函数

#### 🍎 food.js - 食物管理
- 生成3-5个随机食物
- 避免与蛇身重叠
- 食物颜色管理和移除逻辑

#### 🎨 renderer.js - 渲染系统
- 画布绘制和清空
- 网格、蛇、食物的渲染
- 无限循环模式边界箭头

#### 🖱️ ui.js - UI控制
- DOM元素管理和事件绑定
- 按钮状态更新
- 分数显示和状态文本更新
- 键盘输入处理
- 游戏记录模态框显示和管理

#### 🎲 game.js - 主游戏逻辑
- 各模块协调
- 游戏循环控制
- 碰撞检测和食物处理
- 游戏状态转换

#### 🚀 main.js - 入口文件
- 创建游戏实例
- DOM加载完成后初始化

## 🎯 操作说明

### 键盘控制
- **方向键**：控制玩家蛇移动
- **空格键**：暂停/继续游戏

### 按钮功能
- **开始游戏**：开始新游戏
- **暂停**：暂停当前游戏
- **重新开始**：重置游戏状态
- **难度选择**：简单/中等/困难
- **速度滑块**：调整游戏速度
- **音乐开关**：控制背景音乐
- **音效开关**：控制游戏音效
- **无限循环开关**：切换游戏模式
- **游戏记录**：查看历史游戏记录和统计信息

## 🏆 游戏规则

1. **目标**：与AI蛇竞争，尽可能多吃食物获得高分
2. **生命**：每轮游戏有3条生命，碰撞后失去一条生命
3. **食物**：棋盘上同时存在3-5个食物，全部吃完后重新分配
4. **碰撞**：
   - 无限循环模式：只检查自身碰撞
   - 经典模式：检查边界碰撞和自身碰撞
5. **AI**：AI蛇会智能选择最近的食物进行移动

## 🛠️ 技术特点

- **零依赖**：纯原生JavaScript，无需任何框架
- **模块化**：使用ES6模块系统，代码结构清晰
- **面向对象**：使用类来组织代码，提高可维护性
- **响应式**：适配不同屏幕尺寸
- **Web Audio API**：程序化生成音乐和音效
- **Canvas渲染**：流畅的游戏画面
